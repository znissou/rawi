# Research notes (2026-11-09)

Facts gathered in the session where rawi was named. They are a snapshot: re-check anything that can change, especially model lists and prices.

## The extension rawi replaces

**Read Aloud for Claude Code** by Abdalrhman Attar: `abdalrhman-attar.read-aloud-for-claude-code` 0.6.2, **MIT licence**, so its ideas and code can be reused as long as the copyright notice is kept. It's installed at `~\.vscode\extensions\abdalrhman-attar.read-aloud-for-claude-code-0.6.2\` (the version folder changes on update). A thin VS Code extension (`out/extension.js`) drives a local Python server in `bundle/server/` (about 2,900 lines). Its own description: "Hear Claude Code replies read aloud with a natural local voice, and replay any sentence. One-click setup; also works with Codex, Gemini CLI and Cursor."

### How it gets replies
- **Claude Code, with no hook.** `transcripts.py` polls `~/.claude/projects/*/*.jsonl` every second.
  - A reply is the text of a turn's final assistant message (`stop_reason: "end_turn"`): the part after its last tool call. Subagent messages (`isSidechain`) are skipped.
  - Files that exist at start-up are followed from their current end, so old replies are never re-spoken. Only files written in the last 15 minutes are followed, and a file must stay quiet for 1.5 s before its reply is spoken.
  - The session title comes from `ai-title` lines (`aiTitle`), and the working folder from `cwd`. The folder is how it lists only replies from the current window's folders.
- **Other agents, through their hooks** (`agent_hook.py`):
  - Codex: `notify` (`type: agent-turn-complete`, text in `last-assistant-message`).
  - Gemini CLI: `AfterAgent` (`prompt_response`), and `Notification` for permission prompts, spoken as "I need permission to use X".
  - Cursor: `afterAgentResponse` (`text`).

  The hook returns at once and a detached worker speaks, so the agent never waits on the voice.
- **An MCP server** (`mcp_server.py`) with `speak` and `stop_speaking` tools, for any MCP client.

### How it speaks
- `server.py` is a Kokoro server that keeps the model loaded. It takes JSON requests over a Unix socket, or a localhost TCP port with a random token (`transport.py`), queues replies across sessions, and exits when idle.
- `markdown.py` turns Markdown into speakable sentences with pauses (0.5 s between paragraphs, 0.25 s between lines). It announces code blocks by language, and its sentence splitting ignores abbreviations and list numbers.
- **Arabic** (Kokoro has no Arabic voice):
  - Text is diacritized first (`shakkelha.py`, `catt/`) and numbers are converted (`arabic_numbers.py`).
  - It's then spoken by NVIDIA MagpieTTS Multilingual 357M, run locally through NeMo-Speech.cpp (`magpie.py`), or by the OS voice (`system_voice.py`: SAPI on Windows, `say` on macOS, espeak-ng on Linux).
- `mic.py` pauses speech while something records from the microphone (by default only voice typing and dictation).

### Settings and commands
- **VS Code settings:** only `claudeVoice.home` and `claudeVoice.onlyThisWorkspace`.
- **Its own Speak pane** keeps the rest in a `settings.json` in its home folder (`KOKORO_HOME`, by default `~/.claude/kokoro`): `voice`, `speed`, `summarize`, `muted` / `mutedUntil`, `awayOnly`, `projectVoices`, `arabicVoice`.
- **Commands:** play latest reply, pause or resume, skip sentence, stop, mute auto-speak, show replies, set up the voice, add the Arabic voice.

### What it lacks (why rawi exists)
- No cloud engine. English is Kokoro-only, so a device that can't run Kokoro gets no English voice at all.
- Free or better cloud models (for example on OpenRouter) can't be used.
- "Summarize" is a first-paragraph cut, not a summary.

## OpenRouter text-to-speech

### The API
- **Endpoint:** `POST https://openrouter.ai/api/v1/audio/speech`, compatible with OpenAI's Audio Speech API. The OpenAI SDK works with `base_url="https://openrouter.ai/api/v1"`.
- **Request body:** `model`, `input`, `voice`, `response_format` (`mp3` returns `audio/mpeg`, `pcm` returns `audio/pcm`). The `X-Generation-Id` response header identifies the request.
- **Docs:** <https://openrouter.ai/docs/guides/overview/multimodal/tts>. They also cover voice cloning, multi-speaker input and provider-specific options.
- **Model discovery:** `GET https://openrouter.ai/api/v1/models?output_modalities=all` needs no key. Keep the models whose `architecture.output_modalities` contains `"speech"`; there were 38 on 2026-11-09. `?output_modalities=speech` returns only those. Each model also lists its voices (`supported_voices`) and, for temporary ones, an `expiration_date`.
- **Prices:** for character-billed models, `pricing.prompt` is USD per character. For example, Deepgram Flux TTS shows `0.000045`, and its model page says $45 per million characters. Gemini TTS and Seed Audio also bill output (`pricing.completion`).

## Name check
- **Method:** the VS Code Marketplace gallery API (`extensionquery` with search text) and the Open VSX search API (`/api/-/search`). A name counted as taken when a display name or extension name equalled the candidate or started with it.
- **Free on both:** rawi, sawt, Earshot and Sotto (the shortlist), plus qawl, nutq, hadra, Hearsay, Spiel, Natter, Recite, Orator, Polyvox and Anyvoice.
- **Taken:** Readback (`speechify.readback`, Speechify is a TTS company) and Herald (`leighlondon.herald` and others).
